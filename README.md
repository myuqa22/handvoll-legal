# handvoll-legal

Datenschutzerklärung, Impressum und Support der App Handvoll als GitHub Pages; `support.md` wird hier gepflegt, nicht von `sync.sh`.
Quelle sind die Texte in der App (`Handvoll/Handvoll/Resources/*.md`); `./sync.sh` übernimmt sie, danach committen und pushen.
Pages: Settings → Pages → „Deploy from a branch“, `main` / root.
